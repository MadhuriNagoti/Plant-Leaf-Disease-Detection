# Plant-Leaf-Disease-Detection
The "LEAF SENSE: SMART LEAF DISEASE DETECTION SYSTEM" is the application that 
utilizes sophisticated machine learning algorithms such as Mobile Net and Reset in order to identify 
plant diseases by uploading the leaf images into the system. The system further analyses the visual 
data with the help of algorithms in detecting diseases and provides the user with descriptions and 
treatment options. The system offers the capability of producing output in several languages, wherein 
apart from audio description, the TTS capabilities will produce the same in Telugu, Hindi, English, 
Tamil, Kannada, and Malayalam. Assuring proper identification of disease will take place while 
assuring appropriate prescription so that proper management agriculture can occur with improved 
health of crops. 
Both the ResNet models were used exceptionally outstandingly. Thus, Mobile Net is a light- weight 
architecture on which it can easily be deployed on low computational devices like that in embedded 
systems and tablets. This ensures that "LEAF SENSE" can be used in the field without any hardware as 
well as on end-intensive hardware. The ResNet is also pretty famous for its deep learning abilities and 
is taken very deep into the trees so as to achieve the capability to provide high-level accuracy 
concerning the image classification. Bringing in a fusion of both models' efficiency along with the 
precision makes the system bring in the effective detection of plant diseases.
